Sanctuary Operations Data Platform

A full-stack Flask app for dog sanctuary operations: auth, intake, care logs, adoptions, and reporting.

Features

  • Secure authentication with hashed passwords and CSRF protection
  • Role-based access (admin vs staff)
  • Dog intake, edits, and soft-archiving
  • Care logs with optional costs and per-dog rollups
  • Adoption applications with approval workflow
  • Reporting dashboards: status counts, monthly trends, cost drivers

Run locally

Clone the repo, then:

python3.11 -m venv .venv
# Windows: .venv\Scripts\activate
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # then edit .env
alembic upgrade head
python run.py
